# ccpod 安全与风险说明

**请在安装前读完这一页。** 这个工具会接触到你所有 AI 线路的密钥，你有权在知情的前提下决定要不要用。

---

## 1. 这个软件能碰到什么

ccpod 是一个 macOS 菜单栏工具，用来管理 Claude Code 的会话与中转线路。为了能干活，它需要读到：

| 它碰得到的东西 | 为什么需要 | 存在哪 |
|---|---|---|
| 你的**线路密钥**（api key） | 启动会话时注入环境变量、查询余额 | macOS 钥匙串 + CCR 网关数据库 |
| 你的**会话记录**（`~/.claude/projects/*.jsonl`） | 显示每个对话的标题、在用的模型、最后活动时间 | 只读，不上传、不复制 |
| 你的**进程列表** | 找出正在运行的 claude 会话 | 只读 |
| 你的**终端** | 「关闭会话」「新窗口继承切线」要往终端发指令 | 会向 TTY 注入命令 |

它**不会**做的事：不联网上报、不做遥测、不把你的对话内容发给任何第三方模型。
（曾经有过一个「自动批准」功能会把工具调用摘要发给第三方模型做风险判断，**已于 2026-09-26 整体下线并删除代码**，原因正是隐私。）

## 2. 威胁模型：什么情况下你会出事

| 场景 | 后果 | ccpod 的防护 | 残余风险 |
|---|---|---|---|
| **本机有其他用户 / 恶意进程** | 读走你的线路密钥 | 所有含密钥的文件强制 `600`、目录 `700`；密钥本体存钥匙串，配置文件里只留"去钥匙串取"的引用 | 以你的身份运行的进程仍能读钥匙串——这是 macOS 的信任边界，任何本地工具都一样 |
| **CCR 网关（第三方开源软件）被入侵或坏更新** | 你**所有上游线路的密钥**一起泄露 | 数据库 `600`、升级前先备份、`ccr-upgrade.sh` 带盲打验证、`ccdoctor` 报版本 | ⚠️ **这是本架构最大的结构性代价，无法根治**：只要用一个第三方网关聚合线路，密钥就集中在它手里。换来的是统一路由、鉴权与限额 |
| **配置文件被备份/同步/截图/误提交** | 密钥外泄 | 仓库内 0 处明文；`.gitignore` 挡了 `*.secret.json`/`*.local.json`/`*.key`；密钥不进任何 json | 你自己手动把明文写回 json 的话，防护就失效了——`ccpod-key doctor` 会报出来 |
| **你粘贴的报错原文里带着密钥** | 密钥被长期留在诊断历史里 | 落盘前自动脱敏（`sk-…`/`ark-…` 保留前 6 位后打码、`Bearer` 整段打码） | 脱敏靠模式匹配， unusual 格式的密钥可能漏网 |
| **误杀进程** | 丢失未保存的工作 | 关闭会话前验明正身（TTY + 进程环境/命令行三重判据），取不到信息一律不杀 | 判据是启发式的，极端情况下可能"该杀的杀不掉"（宁可如此，也不误杀） |

## 3. 密钥到底存在哪（实测）

```
macOS 钥匙串  ← 权威存放点（ccpod-line-<线路> / ccpod-diag-<用途>）
     ↑ 配置文件里只有一行引用：
       {"$exec": "security find-generic-password -a \"$USER\" -s ccpod-line-xxx -w"}
CCR 网关数据库 ~/.claude-code-router/config.sqlite (600)  ← 上游线路密钥的集中点，见上表风险
```

自查命令（随时可跑，都只读）：

```bash
ccdoctor            # 安装/运行一致性 + 密钥卫生（含明文密钥的文件必须 600）
ccpod-key doctor    # 专扫配置文件里还有没有明文密钥
ccpod-key list      # 看钥匙串里有哪些条目（只显示名字与指纹，绝不显示密钥）
```

## 4. 安全审查的真实状态（不夸大）

- ✅ 做过 **3 轮对抗性审查**（2026-09-26）：两个独立视角通读全部 Swift 与 shell/Python，之后再两轮专审"修复本身有没有引入新问题"。台账为内部资料，未随公开版发布；每条带证据与修法。
- ✅ 已修 **17+ 项**，其中包括审查过程中**我自己引入的 2 个高危**（无限等锁可冻死菜单栏、主线程被轮询阻塞）和 1 个会让"关闭会话"全线失效的 bug。
- ❌ **没有经过任何第三方独立安全审计**，也没有任何机构背书。上面的审查是作者自审 + AI 辅助对抗性审查。
- ❌ **这是一个个人项目**，目前不公开用户数、也没有社区规模可以引用。如果你需要"很多人在用所以安全"这种保证，这个项目现在给不了。
- ⚠️ 台账里还有 **12 项中危 + 10 项低危未修**（多数与已下线的审批功能有关，优先级已降低）。清单在同一份文档第三节。

**一句话**：这个工具的密钥处理是按"发布给别人用"的标准硬化过的（钥匙串 + 600 权限 + 落盘脱敏 + 可自查），但它**没有第三方审计背书**，请自行判断风险。

## 5. 出问题怎么办

```bash
# 彻底卸载（会移除命令软链；不会删你的密钥与会话记录）
./uninstall.sh

# 怀疑某把密钥泄露：先在钥匙串里换掉，再让配置跟上
security add-generic-password -a "$USER" -s ccpod-line-<线路名> -w '<新密钥>' -U
ccpod-key doctor          # 确认没有明文残留

# 想让某个功能彻底停掉：审批功能已经这么做了，可参考
#   install.sh 第 5 节（从 settings.json 摘除 hook 的写法）
```
